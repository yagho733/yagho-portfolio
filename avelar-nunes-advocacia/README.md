# Avelar Nunes Advocacia

Projeto demonstrativo premium de site institucional jurídico criado para o portfólio Yagho Sites.

## Estrutura

- Home institucional com vídeo e motion editorial
- 5 páginas de áreas de atuação
- 3 páginas de profissionais
- 4 insights/artigos
- Contato com envio organizado para WhatsApp
- Política de privacidade e página 404
- SEO técnico, Open Graph, JSON-LD e sitemap
- Experiência mobile com o mesmo vídeo e direção visual do desktop

## Observação

Avelar Nunes é uma marca fictícia de demonstração. Nomes, perfis e conteúdos devem ser substituídos pelos dados reais do cliente antes de qualquer publicação comercial.
